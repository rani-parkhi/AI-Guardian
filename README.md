# AI Guardian

AI Guardian is a Responsible AI Security Platform designed to detect AI misuse and provide transparent risk explanations.

## Modules

- Prompt Risk Analyzer
- Explainable AI

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- Chart.js

### Backend
- FastAPI
- Python
- SQLAlchemy
- PostgreSQL

### AI/ML
- Hugging Face Transformers
- Llama 3 / GPT API
- Microsoft Presidio
- scikit-learn
